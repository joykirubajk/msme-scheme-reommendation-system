# Task script

Read each task exactly as written. Do not point at the screen or name buttons. If the participant is stuck for 60 seconds, ask "What would you try next?"; if still stuck after 2 minutes, help them and mark the task **P** (with help). Start the timer when you finish reading; stop it when they say they are done.

Give each participant one persona card at the start (rotate A, B, C so each is used about equally).

---

**T1 - Create an account**
> "Please create an account on this website for yourself. You can use a made-up email address."

Success: signed in and their name is shown in the header.

**T2 - Get recommendations**
> "Using the details on your card, find out which government schemes this business could apply for."

Success: the results list appears with at least one scheme.

**T3 - Understand the top result**
> "Look at the scheme at the top of your list. Tell me in your own words why the website thinks it suits this business."

Success: they open "Why this matched" (or the details) and state at least one correct reason, e.g. "because it is for women in Tamil Nadu".

**T4 - Browse with filters**
> "Now forget the recommendations. Find every scheme on the website that is available in Tamil Nadu for a manufacturing business with a project cost of five lakh rupees. How many are there?"

Success: Browse page with State = Tamil Nadu, Business type = Manufacturing, project cost 500000, and they read out the count.
(Expected count with the current 22 sample schemes: **13**. Re-check it before the study if the scheme data has changed.)

**T5 - Save and remove**
> "Save one scheme you find interesting so you can come back to it later. Then find the list of schemes you have saved, and remove it again."

Success: scheme appears in My Saved Schemes and is then removed.
