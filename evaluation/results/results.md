## How to read this honestly

- The personas, spot checks and relevance grades were written by the developer. They are not real users and not official eligibility decisions.
- The reference implementation reads the same rules as the engine, so engine-vs-reference agreement shows the code matches the documented rules; it does not prove the rules match the real schemes.
- The ranking weights were set by hand before this evaluation and were not tuned on these personas.
- Recommended lists are short (1-9 schemes) and there are only 22 personas, so small differences between orderings are not meaningful. Where the list has 1-2 schemes every ordering scores the same.
- Low scores usually mean a scheme is eligible by its rules but off-topic for the person (for example a food-processing scheme for a garment unit): the rules allow any manufacturing business, and the text signal is weak on short descriptions.
